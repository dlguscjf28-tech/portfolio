# HyunchulPortfolio.com

Standalone game portfolio for Render. Public visitors do not need an account. Editing requires administrator authentication.

## Deploy

Use render.yaml to provision a Node web service with a 1 GB persistent disk. Set ADMIN_PASSWORD to a unique password of at least 12 characters directly in Render; SESSION_SECRET is generated by Render. Do not put secrets in Git.

The build is npm install --include=dev && npm run build; start with npm start. DATA_DIR must point to the persistent disk mount (/var/data). Native file upload supports 100 MB per file; single-file HTML games execute in a sandbox. Multi-file game builds use an external hosting URL.

## Verify

npm test checks public access, authenticated edits, unpublished file access, optimistic concurrency and persistence across server restarts.

## Domain

The visible title is HyunchulPortfolio.com. Connecting that exact custom domain requires ownership and DNS configuration. The Render service supplies an onrender.com address.
